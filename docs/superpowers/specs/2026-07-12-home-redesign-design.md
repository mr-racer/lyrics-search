# Редизайн главной («Эфир») — дизайн-спека

Дата: 2026-07-12. Согласовано в брейншторме с визуальными макетами
(`.superpowers/brainstorm/1460-1783803316/content/layout-v5.html` — финальная итерация).

## Цель

Главная перестаёт быть витриной «что показать» (артист дня, случайная песня) и
становится развилкой трёх основных путей: **Поток**, **ИИ-поиск по тексту**,
**Библиотека**. Жёсткие стеклянные карточки-рамки уходят; зоны разделяются
воздухом, светом и осями, стекло остаётся только на интерактивных элементах
(скевоморфизм + liquid glass — текущий язык приложения).

## Что убираем

- `FeaturedArtistCard` («Артист дня») — с главной (desktop-рельса и mobile-стек).
- `DiscoverNewCard` («Что-то новое») — целиком.
- `LibraryPill` из шапки — библиотека теперь полноценный путь на странице.
- Мёртвый код после сноса: `railCardStyle`, `homeGapBadge`, `homeDeriveDifferent`
  (используются только этими карточками) и `LibraryPill`, если не остаётся других
  потребителей. CSS `.efir-rail` больше не нужен.
- Бэкенд не трогаем: `/library/featured-artist`, `/library/rediscover`,
  `/library/top-pairs` остаются (их используют/могут использовать другие экраны);
  главная просто перестаёт их звать.

## Раскладка (desktop)

Центрированный контейнер `max-width: 1380px`, две колонки `flex 1.4 / 1`,
`gap: 64px`. Без бордеров у зон; фон страницы — текущий радиальный градиент +
**аврора**, растекающаяся из-за героя (3 блоба, blur ~34px), в палитре орба
(см. ниже), приглушённая (альфа ≤ .35).

```
┌ header: бренд · мини-плеер (по центру) · [🔍 спотлайт] [◐] [RU] [⚙] ┐
│                                                                      │
│  ГЕРОЙ (flex 1.4)                    ПРАВОЕ КРЫЛО (flex 1)           │
│  ▮▮ ТВОЙ ВАЙБ                        ✦ ПОИСК ПО ТЕКСТУ               │
│  «вайб-фраза» (serif italic,          подпись-пояснение              │
│   clamp до ~28px)                     [✦ живое поле…        ИИ]      │
│  (орб 112px) ВКЛЮЧИТЬ ПОТОК                                          │
│              подпись                 ◉ ФОНОТЕКА                      │
│              [⚙ НАСТРОИТЬ ВОЛНУ ▾]    [Библиотека → | веер обложек]  │
│              └ панель-спойлер                                        │
│  ЯКОРЯ ВКУСА (мини-обложки)                                          │
│  ВАЙБИКИ · [чип][чип][чип]  ← прижаты к низу героя                   │
└──────────────────────────────────────────────────────────────────────┘
```

Адаптив:
- **>1200px** — контейнер по центру, пустота уходит в поля страницы.
- **900–1200px** — gap 36px, орб ~96px, вайб-фраза по clamp() ужимается.
- **720–900px** — правое крыло опускается ПОД герой: поиск и библиотека в один
  ряд 50/50, вайбики над ними.
- **<720px (mobile)** — одна колонка: вайб-фраза + орб → поле поиска по тексту →
  вайбики горизонтальной лентой (scroll) → карточка библиотеки. Якоря вкуса
  скрыты (как сейчас). Раскрытая настройка волны везде выпадает под пилюлю.

Типографика укрупняется: kicker'ы 11.5px (сейчас 9.5–11), подпись орба 14px
mono, пояснения 13.5px, вайб-фраза `clamp(20px, 2.2vw, 28px)`.

## Герой «Твой вайб»

Существующий `ForYouHero` перерабатывается, поведение орба/запуска потока
(`onStartStream`, `streamActive`, play/pause, `OrbProgressArc`) сохраняется.

### Орб — цвет от вкусовых осей

`/recommend/profile` уже отдаёт `axes` (6 осей: z-score + level). Маппинг ось →
hue:

| ось          | hue  |
|--------------|------|
| energy       | 20°  |
| brightness   | 48°  |
| acousticness | 145° |
| spacious     | 200° |
| experimental | 275° |
| vocal_lead   | 330° |

Берём две оси с наибольшим `|z|`: top-1 — базовый hue градиента орба, top-2 —
второй стоп. Палитра **пыльная**: насыщенность `clamp(|z|) → ~40–55%`,
светлота фикс. полосами (светлый блик → середина → тёмный низ, как в макете
v5: «пыльный закат», «туманная лагуна», «сумерки»). Те же два hue красят
аврору страницы и тёплое гало орба. Переход цвета плавный (~1.6s, как сейчас
у блобов). Фолбэк (нет профиля/осей): текущий фирменный фиолетовый.
Существующая заливка блобов из обложек якорей (`useCoverColor`) уходит в
пользу осевой палитры (обложечные hue можно оставить третьим блобом авроры).
Для светлой темы те же hue, светлота/альфа по существующим токенам `useColors`.

### Орб — эффекты (сдержанно)

- **Покой**: как сейчас (breathe). Hover: рост `scale(1.045)` + внешнее кольцо
  (+6%) + гало (opacity .55). Liquid-параллакс блобов внутри орба сохраняется.
- **Клик (запуск)**: пружинное «нажатие» — `scale 1 → .92 → 1`,
  `.6s cubic-bezier(.34,1.56,.64,1)`, затем состояние «играет».
- **Играет**: медленное дыхание `scale 1↔1.035` (3.2s), пульс гало,
  расходящееся кольцо-рябь (2.6s, из `scale(1), opacity .8` в
  `scale(1.35), opacity 0`). `OrbProgressArc` остаётся.
- `prefers-reduced-motion: reduce` отключает дыхание/рябь/параллакс.

### Настройка волны

Пилюля-спойлер `⚙ НАСТРОИТЬ ВОЛНУ ▾` под подписью орба (вместо нынешней кнопки
«НАСТРОЙКИ ПОТОКА» внизу героя). По клику вниз раскрывается панель на месте
(слот фиксированной высоты, fade — приём как сейчас): слайдер НОВОЕ ↔ ЛЮБИМОЕ
(тот же дебаунс-PUT `/recommend/stream/settings`). Шрифты крупнее нынешних:
метки слайдера 11.5px, строка «70% НОВОГО · 30% ЛЮБИМОГО» 10.5px, пилюля 11.5px.

### Якоря вкуса

Остаются: ряд мини-обложек 40px из `profile.islands` (top-1 трек каждого
острова), клик → артист. Скрыты на мобиле.

### Вайбики (до трёх)

Ряд прижат к низу героя — он же выравнивает высоту колонок. Заголовок ряда:
`ВАЙБИКИ · то, что держит тебя сейчас` (mono kicker). Данные: `profile.vibes`
(уже приходит из `/recommend/profile`, максимум 3). Чип: пилюля-стекло, круглая
мини-обложка (top-трек вайбика), имя (`islandName`-логика: name → артист top-трека),
глиф ▶. Клик — как «радио острова» в рекомендациях:
`GET /recommend/autoplay-queue?seed_track_id={vibe.track_id}&limit=20` →
`onPlayTrack(lead, hits)`. Ряд скрыт целиком, когда вайбиков нет (опциональный
слой, без empty-state). На мобиле — горизонтальная лента со скроллом.

## Правое крыло

Кикер + пояснение живут прямо на фоне (без карточки), стекло — только на
интерактиве.

### ✦ Поиск по тексту (ИИ)

- Кикер `✦ ПОИСК ПО ТЕКСТУ`, пояснение: «Помнишь строчку, а не название? ИИ
  найдёт песню по словам».
- Живое поле-стекло с бейджем `ИИ`. **Без hover-свечения** — hover/focus только
  мягкая подсветка рамки (`border-color`).
- Enter (или клик по бейджу-стрелке) → переход в раздел `search` с передачей
  запроса: SearchSection открывается на вкладке **чат (ИИ)** и сразу сабмитит
  запрос в `handleChat`.
- Механика передачи: App-состояние `searchHandoff` (`{ query, ts }`) →
  проп в `SearchSection`; эффект в SearchSection при маунте/смене подхватывает
  и запускает. Никаких изменений URL-роутинга не требуется.
- **AI недоступен** (`!aiStatus.aiActive`): поле работает как вход в классический
  поиск — та же передача, но вкладка `search` и `handleSearch` (бейдж `ИИ`
  скрыт, плейсхолдер тот же).

### ◉ Фонотека

Кнопка-«веер» (выбранный вариант A): стеклянная плашка, из правого края
выглядывает веер из 3 последних обложек (реальные данные), на hover веер
слегка расправляется (transform у каждой обложки), карточка — tilt + световое
пятно. Контент: «Библиотека →», mono-строка `N АЛЬБОМОВ · M ТРЕКОВ`
(`/library/stats`, как в нынешней `LibraryPill`). Строки «+N новых за неделю»
НЕТ. Обложки: первые 3 альбома с обложкой из `GET /library/albums?sort=year_desc`
(эндпоинт уже существует и используется LibrarySection; сортировки «recently
added» у него нет — берём свежие по году релиза, этого достаточно для витрины).
Клик → `onNav('library')`.

## Шапка

Бренд + `PremiumMark` слева, `HeaderNowPlaying` по центру (без изменений),
справа: **🔍 спотлайт** (вместо нынешней навигации в раздел поиска), ◐ тема,
RU/EN, ⚙ настройки. Иконка 🔍 открывает спотлайт-оверлей (поиск по песням).
Горячая клавиша `Ctrl/Cmd+K` — глобально во всём приложении. Раздел `search`
в `FloatingIconNav` остаётся как был (это другой путь — полноэкранный поиск).

## Спотлайт-поиск по песням (новый компонент)

Глобальный оверлей поверх любого экрана (как Spotlight в macOS):

- Затемнение `rgba(5,4,10,.55)` + blur подложки; стеклянная строка ввода по
  центру, ~15vh от верха; автофокус. Esc / клик мимо — закрыть.
- Данные: `GET /library/browse?q=&limit=8`, дебаунс ~150ms, минимум 2 символа.
- Строка результата: обложка 44px · заголовок 14.5px + подстрока
  `артист · альбом {album} · {year}` · справа: жанр-тег (mono, рамка) ·
  отступ · длительность (mono) · кнопка **«+» в плейлист**.
- **Клик по строке = играть** (`onPlayTrack(hit, [hit])`). «+» открывает
  существующий пикер плейлистов (`openAddToPlaylist`), не запуская трек
  (stopPropagation).
- Подсветка активной строки — **одна бегущая пилюля**: absolute-элемент за
  строками, `translateY` к активной строке,
  `transition: .38s cubic-bezier(.34,1.45,.5,1)` (лёгкий баунс). Она же
  движется за hover-курсором и за ↑↓. Никакого спот-свечения в строках.
- Клавиатура: ↑↓ — активная строка, ↵ — играть активную, Tab — уйти в
  библиотеку с этим запросом, Esc — закрыть.
- Футер: слева подсказки клавиш, справа «ЕЩЁ N СОВПАДЕНИЙ →» (клик = та же
  навигация в библиотеку с запросом).
- Пустые состояния: <2 символов — только строка ввода (без панели результатов);
  нет совпадений — тихая строка «Ничего не нашлось в библиотеке».

### Бэкенд-правка (единственная)

`MetadataDB.get_browse_rows` и Qdrant-фолбэк в `browse_tracks` дополняются
полями `year`, `genre`, `duration` (в зеркале `track_metadata` они уже есть;
в Qdrant-скролле — добавить в `with_payload`). Поля опциональны: фронт
рендерит тег/год/длительность только при наличии.

## Экран поиска (SearchSection) — смена дефолта

- Начальная вкладка: `chat` при `aiActive`, иначе `search` (сейчас всегда
  `search`). Существующий эффект «AI пропал → снап на search» остаётся.
- Приём `searchHandoff` с главной: на вкладке чат — автосабмит `handleChat(query)`;
  на классической — `setSearchQuery(query)` + `handleSearch()`.

## Грамматика курсора (сдержанно)

Переиспользуем приёмы RecommendSection (CSS-переменные, без ре-рендеров):

- **Световое пятно** (`--mx/--my`): карточка библиотеки, чипы вайбиков.
  НЕ на поле поиска, НЕ в строках спотлайта.
- **Tilt ±6°** (`--rx/--ry`): только кликабельное — карточка библиотеки, чипы
  вайбиков. Орб вместо tilt сохраняет свой liquid-параллакс.
- Статичные панели (настройка волны, панель результатов) — без эффектов.
- `spotHandlers`/`lqHandlers` сейчас определены внутри RecommendSection —
  вынести на модульный уровень и шарить.

## Ошибки и деградация

- Нет профиля/Qdrant лежит: орб в фолбэк-фиолетовом, вайбики и якоря скрыты,
  вайб-фраза → существующий фолбэк «Начнём с разведки». Пути поиска и
  библиотеки работают всегда.
- Нет LLM: поле поиска по тексту ведёт в классический поиск (см. выше),
  спотлайт не зависит от LLM вовсе.
- Пустая библиотека: поведение орба как сейчас (тост «Библиотека пуста»),
  спотлайт показывает «Ничего не нашлось».
