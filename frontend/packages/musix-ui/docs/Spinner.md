# Spinner

Кольцевой индикатор загрузки. По умолчанию — фирменный фиолетовый `oklch(60% 0.18 270)`;
`color` задаёт и дугу, и полупрозрачное кольцо-подложку (`color + '30'`).
Требует `@keyframes spin` из styles.css (уже в бандле).

```tsx
import { Spinner } from 'musix-ui';

<Spinner size={16} />                      // в строке, рядом с текстом
<Spinner size={28} color="oklch(72% 0.13 75)" />  // янтарный, крупнее
```

Типичное применение: кнопки в состоянии загрузки, ожидание ответа API, плейсхолдер секции.
