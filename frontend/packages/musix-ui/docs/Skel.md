# Skel

Скелетон-блок с шиммером на время загрузки (классы `.load-skel` / `.load-skel--l`).
Размеры принимают px-числа или CSS-строки.

```tsx
import { Skel } from 'musix-ui';

<Skel w={220} h={16} isDark />          // строка текста
<Skel w="100%" h={46} r={12} isDark />  // карточка/строка списка
<Skel w={44} h={44} r={10} isDark />    // обложка
```

Собирайте из нескольких блоков силуэт будущего контента.
